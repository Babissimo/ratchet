What it does

Start, stop, switch
Start a timer on any task, or on the last one you tracked in a single click. Switching task moves the running timeslip rather than starting another, so it stays one continuous entry.
Log time after the fact
Book a duration and comment to any day you missed, from the same client, project and task picker.
Correct mistakes
Unbilled entries under Recent time entries open for editing. Invoiced ones are listed but locked, as FreeAgent locks them.
Create as you go
Add a client, project or task from inside the picker when the one you need does not exist yet.
Straight to FreeAgent
You sign in to FreeAgent in your browser and Ratchet talks to its API directly. A small sign-in service holds Ratchet's FreeAgent app credentials and stores nothing; your time entries never pass through it. There is no Ratchet account, and your sign-in tokens stay in the macOS Keychain.

Install

Ratchet needs macOS 13 or later, on an Intel or Apple silicon Mac.

With Homebrew
brew install babissimo/ratchet/ratchet

Upgrade later with brew upgrade ratchet, then open Ratchet again.

As a download
Download Ratchet.app.zip from the latest release, unzip it, and move Ratchet.app to Applications. Ratchet isn't notarised by Apple, so macOS refuses to open a downloaded copy the first time; the README explains how to let it through. Homebrew installs skip this.
